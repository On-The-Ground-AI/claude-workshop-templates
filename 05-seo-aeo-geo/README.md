# 05 · SEO + AEO + GEO

> ⚠️ AI-generated · Reviewed by Haojun See (OTG).

The three letters that decide whether your site gets found in 2026:

- **SEO** — Search Engine Optimisation. Classic Google.
- **AEO** — Answer Engine Optimisation. Making AI assistants (Claude, ChatGPT, Perplexity) cite you when they answer questions.
- **GEO** — Generative Engine Optimisation. Content structured for inclusion in AI-generated answers.

Roughly 80–90% of getting found by AI engines is still classic SEO done right. The other 10–20% is the AEO/GEO layer.
