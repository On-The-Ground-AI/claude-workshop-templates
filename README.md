## Stack we teach

We teach **Claude Code + GitHub + Vercel + Namecheap** end-to-end — that's it. No Cloudflare Pages, no Netlify, no Render, no Squarespace, no Webflow. Narrow is better than confusing. If you use another stack you can adapt these templates, but we won't be writing steps for it.
