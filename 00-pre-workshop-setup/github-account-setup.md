# GitHub account setup

> Time: ~5 minutes. You'll need: an email address.

GitHub is where your CW-2 website code will live. Even if you've never coded, you need a GitHub account so Vercel can deploy your site automatically every time you change it.

## Steps

1. Go to [https://github.com/signup](https://github.com/signup).

   <!-- SCREENSHOT: github-signup.png -->

2. Enter your email, create a password, choose a username.

   - **Username tip:** use your real name or a clear handle. This will appear in URLs like `github.com/yourname/yoursite`. If your name's taken, append your country code or a number.

3. Verify your email (Octocat puzzle + one-time code).

4. Skip the "personalisation" survey on the welcome screen — we'll set that up in CW-2.

5. Sign in to [https://github.com](https://github.com) and confirm you can see your dashboard.

## Recommended: enable 2FA

GitHub will eventually require this anyway. Click your avatar (top-right) → **Settings** → **Password and authentication** → set up two-factor with the Authenticator app of your choice (1Password, Authy, Google Authenticator, etc.).

   <!-- SCREENSHOT: github-2fa-screen.png -->

## What we'll do in the workshop

- Create a private repository for your site.
- Connect it to Vercel for one-click deploys.
- Walk through the simplest possible Git workflow (commit + push from Claude Code).
- Keep your repo private until you're ready to flip it public.

## Don't worry about

- Learning Git on the command line.
- SSH keys vs HTTPS auth — Claude Code handles this.
- GitHub Actions, Codespaces, Copilot — out of scope for CW-2.
