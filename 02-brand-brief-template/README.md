# 02 · Brand brief template

> ⚠️ AI-generated · Reviewed by Haojun Yong (OTG).

Two templates — one for personal brand, one for business. Each is a five-question structure that becomes the file Claude auto-loads at the start of every session.

| File | Use it for |
|---|---|
| [personal-brief.md](./personal-brief.md) | Solo professionals, consultants, freelancers, coaches, creators |
| [business-brief.md](./business-brief.md) | Companies, agencies, startups, SMBs |

## How to use these

1. Copy the relevant template into a file called `brand-brief.md` in your project.
2. Answer the questions in plain English. Don't optimise for AI — write like you'd brief a thoughtful intern.
3. Save the file into your CLAUDE.md import list (or into Google Drive for CW-1).
4. Claude auto-loads it every conversation. The voice carries through every deliverable.

## What "good" looks like

- **Specific over universal.** "We serve B2B SaaS founders in Singapore who sell into enterprise" beats "We help businesses grow."
- **Real examples beat adjectives.** "Like [specific competitor we admire]" beats "innovative and friendly."
- **What we won't do.** Constraints are signal. "We won't take legal-tech clients" tells Claude as much as what you do.
